# Mini Games Hub

A web-based mini-games platform that integrates **Logic & Puzzle, Math & Strategy, and Word & Trivia** games into a single interactive interface.

## Games Included

### Logic & Puzzle
- Tic-Tac-Toe
- Sudoku
- Hangman
- Sliding Puzzle

### Math & Strategy
- Fibonacci Sequence
- Rock-Paper-Scissors
- Guess My Number
- KenKen

### Word & Trivia
- Word Scramble
- Word Chain
- Trivia Quiz

## Technologies Used

- **C (Structured Programming)** – Core game logic and algorithm design
- **HTML5** – Web page structure
- **CSS3** – User interface and styling
- **JavaScript** – Game logic and interaction
- **Local Storage** – Score persistence

## Key Features

- Category-based game navigation
- Interactive gameplay
- Dynamic game logic
- Score tracking
- Responsive user interface

## How to Run

Download or clone the repository and open **`index.html`** in a modern web browser.

## Objective

To develop a unified browser-based platform that demonstrates **web development, JavaScript programming, user interaction, game logic, and score management**.
